GATC：开源的分子克隆工作台，网页打开即用。

读写 SnapGene 的 .dna，质粒图谱、酶切与虚拟电泳、引物设计、Gibson/Golden Gate/Gateway 等克隆模拟、Sanger 与多序列比对；构建历史可导出带断言的 pydna 脚本与 OpenCloning 克隆策略，随文作补充材料，跑一遍即是复核。

以 GPL-3.0 发布，无席位限制，整组共用也不另计费。作为参照，同类商业软件按席位年费订阅，其官网现价学术版单席位 350 美元/年、10 席位 3,250 美元/年（2026-10-29 查）。

计算全部在浏览器内完成，未发表的序列不离开本机。酶定义与切点已与 REBASE 逐条比对，引物 Tm 对 primer3 最大偏差 0.00 °C，克隆产物与 pydna 逐项一致；未覆盖范围同样列明。

SnapGene 为 Dotmatics 商标，本项目为独立实现，与其无关联。
