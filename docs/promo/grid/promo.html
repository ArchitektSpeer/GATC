01 / 图谱与序列
质粒图谱与双链序列
环形与线性图谱并排联动：多轨道特征、防碰撞引线、ORF 与 GC 曲线； 序列区同屏显示酶切阶梯切口、引物与 CDS 翻译。图谱可导出 SVG、300 dpi PNG 与矢量 PDF。
GATCarchitektspeer.github.io/GATC
02 / 酶切分析
580+ 市售酶，3000+ 酶库
跨原点扫描、同裂酶查询、Dam/Dcm/CpG 甲基化阻断判定； 双酶切给出 NEB 缓冲液推荐与星号活性提示。酶定义与切点位置已与 REBASE 逐条比对。
GATCarchitektspeer.github.io/GATC
03 / 虚拟电泳
跑胶之前先看一眼
36 种商业 Ladder，琼脂糖浓度、电压与时间可调； 区分超螺旋、开环与线性构象，条带亮度按质量占比计算。酶切产物可直接送入泳道。
GATCarchitektspeer.github.io/GATC
04 / 引物与克隆
引物设计与11 类克隆向导
Tm 按 SantaLucia 1998 + Owczarzy 2008 盐校正，发夹与二聚体 ΔG 用动态规划求解； 向导覆盖酶切连接、Gibson、Golden Gate、Gateway、TA/TOPO、LIC、重组酶与定点突变。
GATCarchitektspeer.github.io/GATC
05 / 测序
Sanger 峰图比对到质粒
读入 .ab1：Mott 修剪、杂合双峰识别、跨原点比对， 并给出每处差异在氨基酸层面的影响。也支持 FASTQ 读长比对与多读长覆盖度。
GATCarchitektspeer.github.io/GATC
06 / 多序列比对
引导树 + 渐进式比对
DNA 与蛋白（BLOSUM62）均可，给出一致性序列、保守度与同一性矩阵。 内层循环编译为 WebAssembly，比原 JavaScript 实现快约 3.5 倍，且保留等价实现作回退。
GATCarchitektspeer.github.io/GATC
07 / 多步方案
整条路线先算一遍
把克隆路线写成有向无环图，12 种操作按拓扑序逐步计算； 每一步调用与对应向导相同的引擎，某步失败只拦住依赖它的分支，确认后才写入工作区。
GATCarchitektspeer.github.io/GATC
