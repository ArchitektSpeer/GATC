# Cross-check against independent tools

`npm run crosscheck` (needs Python 3 and network access for the first run) compares GATC with
independent implementations on real files written by SnapGene itself: 7 plasmids from the
SnapGene plasmid library (pUC19, pBR322, pACYC184, pBluescript II KS(+), pcDNA3.1(+), pEGFP-N1,
pYES2) and the 8 SnapGene test files shipped with Biopython.

| Check | Reference | Result (2026-10-27) |
|---|---|---|
| `.dna` import: sequence, topology, features (type, name, strand, segments), primers | Biopython `SeqIO` SnapGene parser + raw Features XML | 15/15 files identical |
| `.dna` export: GATC-written files read back | Biopython `SeqIO` SnapGene parser | 15/15 files identical |
| Enzyme definitions | REBASE via Biopython `Bio.Restriction` | 699/699 shared enzymes identical |
| Cut positions, 7 plasmids + 40 kb random sequence | REBASE via Biopython `Bio.Restriction` | 5592/5592 identical |
| Primer Tm (304 oligos, 50 mM Na⁺, 2 mM Mg²⁺, 0.8 mM dNTP, 250 nM) | primer3 (SantaLucia 1998 + Owczarzy 2008) | max difference 0.00 °C |
| CDS translations | protein stored in the SnapGene file | 8/8 identical |
| Restriction digests (1–3 enzymes, top-strand fragments) | pydna | 164/164 identical |
| PCR products (with 5′ tails, across the origin) | pydna | 105/105 identical or both flag non-specific priming |
| Restriction cloning (PCR insert + vector, both orientations) | pydna | 15/15 identical |
| Gibson assembly (2–6 fragments, some reversed) | known answer | 28/28 identical |
| Golden Gate, BsaI (2–5 parts) | known answer | 9/9 identical |

## Defects this found and fixed

- A whole-circle SnapGene feature that starts after the origin (`range="3-2"`) was read as empty
  and dropped on export.
- MluCI, PspFI and BmgT120I had wrong cut positions in the upstream enzyme table; TaqII,
  BspD6I, TscAI and TspRI had non-REBASE sites. All are now corrected from REBASE
  (`src/modules/seq-engine/rebase-overrides.ts`, generated by `gen_rebase_overrides.py`).
- 22 enzymes that cut on both sides of their site (BaeI, BcgI, CspCI, BsaXI, AloI, …) only
  reported the downstream cut; both cuts are now reported and used by digests.
- 26 enzymes for which REBASE has no known cut position were shown with an invented one; they
  are removed.
- Ligation of a sticky-ended fragment that has to be reversed put its overhang on the wrong
  junction (one junction gained 4 bp, the other lost 4), so directional cloning products were
  wrong whenever the insert went in reversed.
- PCR did not warn when a primer's 3′ end can also anneal to the opposite strand.

## Not covered

- Opening GATC-written files in SnapGene itself (Biopython is an independent reader, not SnapGene).
- 3011 enzymes in the database are not in Biopython's REBASE subset (mostly isoschizomer and
  historical names), and 15 of 550 commercial enzymes could not be checked.
- Gateway, TA/TOPO, LIC, Cre/Lox, mutagenesis primers, Sanger alignment and the virtual gel
  have unit tests only.
