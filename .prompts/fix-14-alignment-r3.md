## 跨模块约定（模块间不能 import，靠约定对齐）
- **多段特征**（GenBank `join(...)` / SnapGene 多 Segment）：
  - `SequenceFeature.notes.segments = ["s-e", "s-e", ...]`，每段为 0-based 左闭右开的文档坐标字符串（如 `"10-200"`），按生物学顺序排列；负链特征按 5'→3' 顺序。
  - 该特征的 `start`/`end` 为第一段起点到最后一段终点的整体覆盖区间（环状跨零点同样适用）。
  - 没有 `segments` 的特征视为单段。
- **蛋白文档**（schema 中没有，由各模块用相同结构各自声明，不得 import 彼此）：
```ts

```

## 任务：批量 Sanger 一致性/覆盖度、FASTQ 读长比对

```ts
export interface CoverageSummary { depth: number[]; consensus: string; status: Array<'match' | 'mismatch' | 'heterozygous' | 'uncovered' | 'conflict'>; discrepancies: Array<{ refIndex: number; refBase: string; calls: Array<{ traceId: string; base: string; quality: number }> }>; coveredFraction: number }
export function summarizeTraceCoverage(refSequence: string, traces: SangerTraceData[], opts?: { minQuality?: number }): CoverageSummary
export function alignReadsToReference(reads: SequencingRead[], ref: PlasmidDocument, opts?: { minIdentity?: number; maxReads?: number }): Array<{ readId: string; aligned: boolean; refStart: number; refEnd: number; strand: 1 | -1; identityPercent: number; mismatches: Array<{ refIndex: number; refBase: string; readBase: string }> }>
export function readsToTraces(reads: SequencingRead[]): SangerTraceData[]
```

### summarizeTraceCoverage
- 输入为已带 alignment 的 trace。
- 在参考序列的每个位置汇总所有读长的碱基与质量。
- 多数一致记为 match。
- 不同读长之间互相矛盾记为 conflict。
- 支持跨零点比对。

### alignReadsToReference
- 采用 k-mer 种子 + 带状比对。
- 正反两条链都尝试，环状参考序列支持跨零点。
- 性能：1000 条 150 bp 读长比对到 10 kb 参考序列 < 3 s。

### readsToTraces
- 将 FASTQ 读长包装成 SangerTraceData（traces 为空数组，trimRange 取整条读长），以便复用现有的 Sanger 视图。
