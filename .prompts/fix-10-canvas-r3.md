## 跨模块约定（模块间不能 import，靠约定对齐）
- **多段特征**（GenBank `join(...)` / SnapGene 多 Segment）：
  - `SequenceFeature.notes.segments = ["s-e", "s-e", ...]`，每段为 0-based 左闭右开的文档坐标字符串（如 `"10-200"`），按生物学顺序排列；负链特征按 5'→3' 顺序。
  - 该特征的 `start`/`end` 为第一段起点到最后一段终点的整体覆盖区间（环状跨零点同样适用）。
  - 没有 `segments` 的特征视为单段。
- **蛋白文档**（schema 中没有，由各模块用相同结构各自声明，不得 import 彼此）：
```ts
export interface ProteinFeature { id: string; name: string; type: string; start: number; end: number; color: string; notes?: Record<string, string[]> } // 氨基酸坐标，0-based 左闭右开
export interface ProteinDocument { id: string; name: string; sequence: string; description?: string; features: ProteinFeature[]; createdAt: string; updatedAt: string }
```
- **FASTQ / 测序读长**：
```ts
export interface SequencingRead { id: string; name: string; sequence: string; qualities: number[] } // Phred
```

## 任务：线性图谱、图谱显示选项、多段特征、蛋白视图、Sanger 覆盖度、打印

### 1. `LinearPlasmidMap`（新组件，index 导出）
用于线性片段（也可用于环状质粒展开显示）的横向图谱。
```ts
export interface MapDisplayOptions {
  hiddenFeatureTypes?: string[];   // 不显示的 FeatureType
  showFeatures?: boolean; showEnzymes?: boolean; showPrimers?: boolean; showOrfs?: boolean;
  showFeatureLabels?: boolean; showEnzymeLabels?: boolean;
  labelFontSize?: number;          // 默认 11
  showTicks?: boolean; tickInterval?: number | 'auto';
  showGcPlot?: boolean;            // GC 含量曲线（滑窗）
  showLinearEnds?: boolean;        // 线性片段两端的粘性末端示意
  title?: string; showLength?: boolean;
}
export interface LinearPlasmidMapProps {
  doc: PlasmidDocument; cutSites: CutSite[]; orfs?: ORF[];
  selection: SelectionRange | null; onSelectionChange: (s: SelectionRange | null) => void;
  onFeatureClick?: (f: SequenceFeature) => void;
  displayOptions?: MapDisplayOptions; theme?: 'light' | 'dark' | 'publication';
  width?: number; svgRef?: React.Ref<SVGSVGElement>;
}
```
- 要求：
  - 标尺与刻度。
  - 正链特征画在上方，负链画在下方，用箭头形表示方向。
  - 特征多轨道防重叠。
  - 酶切位点竖线标签防碰撞（与 CircularPlasmidMap 的避让算法风格一致）。
  - 引物用小箭头表示。
  - 支持拖拽选区与点击特征。
  - 输出纯 SVG，可被现有的 exportSvg 导出。
- **CircularPlasmidMap** 新增**可选** prop `displayOptions?: MapDisplayOptions` 和 `orfs?: ORF[]`，并实现与线性图谱相同的显示选项；不传时行为与现在完全一致。
- 新增 `MapDisplayOptionsPanel` 组件：`{ value: MapDisplayOptions; onChange: (v) => void; featureTypes: string[] }`，纯受控，用复选框、滑块、选择框编辑所有选项，紧凑排版。

### 2. 多段特征渲染
按上面的约定，CircularPlasmidMap、LinearPlasmidMap、LinearSequenceEditor 都要识别 `notes.segments`：
- 每段画实体。
- 段与段之间画细线或折线（内含子样式）。
- 箭头只画在最后一段。
- 序列视图中，CDS 翻译按拼接后的序列进行。

### 3. `ProteinSequenceView`（新组件）
- props：`{ protein: ProteinDocument; selection?: {start:number;end:number} | null; onSelectionChange?; theme?; residuesPerRow?: number; height?: number }`。
- 以每行 50 个残基分 10 列显示，带编号。
- 特征以色条显示。
- 残基可按性质着色：疏水、带电、极性。
- 支持拖拽选择。
- 使用虚拟滚动。
- 顶部显示长度、分子量（kDa）、pI，在组件内自行计算。

### 4. Sanger 覆盖度
`SangerAlignmentViewer` 新增**可选** prop `showCoverage?: boolean`：
- 当有多条已比对的 trace 时，在顶部绘制参考序列坐标上的覆盖深度条，以及每个位置的一致性状态：一致、错配、杂合、未覆盖，用不同颜色表示。
- 点击覆盖条时跳转到对应位置。

### 5. 打印
新增函数：
```ts
export function printSvg(svgElement: SVGSVGElement, opts?: { title?: string; landscape?: boolean }): void
export function printSequenceText(doc: PlasmidDocument, opts?: { bpPerLine?: number; showFeatures?: boolean }): void
```
- 实现方式：打开隐藏 iframe，写入打印用的 HTML 与 @page CSS，然后调用 print()。
- printSequenceText 输出等宽的双链序列，每行带编号，下方附特征列表。
- 再写一个可在 Node 下单测的纯函数，用来生成打印 HTML 字符串。
