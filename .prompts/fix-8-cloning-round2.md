## 任务 D：TA/TOPO、LIC、位点特异性重组（Cre/Lox、FLP/FRT）

结合现有的 `simulateLigation`、`simulateGatewayBP` 等实现风格，新增以下 API。所有产物都要带特征坐标迁移（沿用模块内已有的切片/拼接工具），并追加 `history` 节点。CloningOperationType 只能使用 schema 中已有的值：TA/TOPO/LIC 用 'restriction_ligation'，重组用 'manual_edit'。具体方法名写在节点的 description 中，例如 "TA cloning into pCR2.1"。

```ts
export interface CloningProductResult { product: PlasmidDocument | null; orientation?: 'forward' | 'reverse'; warnings: string[] }
export function addATailing(pcrProduct: PlasmidDocument): PlasmidDocument   // 3' A 突出（Taq 产物）
export function simulateTACloning(vector: PlasmidDocument, insert: PlasmidDocument, opts?: { orientation?: 'forward' | 'reverse' }): CloningProductResult
export function simulateTOPOCloning(vector: PlasmidDocument, insert: PlasmidDocument, kind: 'TA' | 'blunt' | 'directional', opts?: { orientation?: 'forward' | 'reverse' }): CloningProductResult
export function simulateLIC(vector: PlasmidDocument, insert: PlasmidDocument, opts?: { vectorEnzyme?: string; tailLength?: number }): CloningProductResult
export function designLICPrimers(template: PlasmidDocument, range: { start: number; end: number }, vectorTails?: { forward: string; reverse: string }): { forward: Primer; reverse: Primer }
export type RecombinationSite = 'loxP' | 'lox2272' | 'lox511' | 'loxN' | 'lox66' | 'lox71' | 'FRT' | 'F3';
export const RECOMBINATION_SITES: Record<RecombinationSite, string>; // 公开序列
export function findRecombinationSites(doc: PlasmidDocument): Array<{ site: RecombinationSite; start: number; end: number; strand: 1 | -1 }>
export function simulateRecombinase(docs: PlasmidDocument[], recombinase: 'Cre' | 'Flp'): { products: PlasmidDocument[]; events: string[]; warnings: string[] }
```

### 各函数行为
- **TA**：
  - 载体必须是带 3' T 突出的线性载体（linearEnds 为 3-prime、序列 "T"），插入片段带 3' A。
  - 如果载体是环状的，给出警告并说明需要先线性化。
  - 两种方向都可以；默认选择使 insert 内第一个 CDS 与载体 lacZ/启动子同向的方向，否则为 forward。
- **TOPO**：
  - TA 规则同上。
  - blunt 要求两侧都是平末端。
  - directional 要求 insert 5' 端以 CACC 开头，并与载体 GTGG 突出配对，方向唯一。
- **LIC**：
  - 用 T4 DNA 聚合酶 3'→5' 外切生成单链尾。
  - 对 vector 和 insert 两侧的互补单链尾做配对校验。
  - 不匹配时 product 为 null 并给出原因。
  - 参考 pLIC/pET LIC 载体的常用尾序列，提供默认值。
- **重组**：
  - 识别同类位点，异种位点不重组，例如 loxP 与 lox2272 不交叉。
  - 单个分子上两个同向位点 → 切除：得到环状小分子与剩余分子。
  - 两个反向位点 → 倒位。
  - 两个分子各有一个位点 → 整合（共整合子）。
  - lox66/lox71 整合后生成 loxP 与双突变的 lox72，并在 events 中说明。

### 测试
- 用合成的载体与插入片段测试 TA 克隆，产物长度 = 载体长度 + 插入长度。
- directional TOPO 只产生一种方向。
- LIC 尾不匹配时返回 null。
- Cre 在同向 loxP 之间切除后，两个产物长度之和等于原长度 + 一个 loxP（34 bp）。
- 倒位后序列为对应片段的反向互补。
- loxP 与 lox2272 混合时不发生重组。
- 特征坐标迁移正确。
