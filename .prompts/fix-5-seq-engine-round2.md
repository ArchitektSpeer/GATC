## 任务 A：酶库扩充、酶集、motif 搜索、反向翻译

### A1 酶库
- `@teselagen/sequence-utils`（MIT）导出 `aliasedEnzymesByName`（约 3700 条，含同裂酶别名）和 `defaultEnzymesByName`（267 条），阅读其真实数据结构（site、topSnipOffset、bottomSnipOffset、isType2S、aliases 等）。
- 新增 `export const ENZYME_DATABASE: RestrictionEnzyme[]`，即全部去重后的酶（按名称去重；转换为 schema 的 recognitionSeq 大写 IUPAC、cutIndexTop、cutIndexBottom、isTypeIIS）。过滤无切割信息或识别序列非法的条目。
- `COMMERCIAL_ENZYMES` 扩充到 **≥ 550 种市售酶**：保留现有 82 种的全部字段（suppliers、nebBuffers、methylation 不变），新增条目来自 defaultEnzymesByName 与你掌握的 NEB / Thermo Fisher / Takara / Promega 等市售目录知识（只加入你确定市售的酶，名称以 REBASE 标准名为准）。为每个新增酶尽可能填写 suppliers 与 Dam/Dcm/CpG 甲基化敏感性（例如 XbaI 与 ClaI 被 Dam 阻断，ApaI/StuI 被 Dcm 影响等，按你确认的公开资料）；未知则不填该字段，不得乱填。
- 名称查询 `getEnzymeByName` 先查 COMMERCIAL_ENZYMES，再查 ENZYME_DATABASE，并支持别名（同裂酶名）大小写不敏感。
- 新增 `export function findIsoschizomers(enzyme: RestrictionEnzyme, pool?: RestrictionEnzyme[]): { isoschizomers: RestrictionEnzyme[]; neoschizomers: RestrictionEnzyme[] }`。识别序列相同、切点相同的为同裂酶；识别序列相同、切点不同的为异裂酶。
- 新增 `export interface EnzymeSet { id: string; name: string; description: string; enzymeNames: string[] }` 和 `export const ENZYME_SETS: EnzymeSet[]`。至少包含以下预设：
  - 常用 6+ 碱基切割酶（约 40 种）
  - NEB HF 酶

  - 平末端切割酶
  - 8 碱基稀有切割酶
  - 4 碱基频繁切割酶
  - pUC19/pET 等常用 MCS 中的酶
  - 归巢内切酶（I-SceI、I-CeuI、PI-SceI 等，如数据中存在）
- 新增 `export function filterEnzymes(pool: RestrictionEnzyme[], opts: { minSiteLength?: number; maxSiteLength?: number; overhang?: Array<'5-prime'|'3-prime'|'blunt'>; typeIIS?: boolean; supplier?: string; nameQuery?: string }): RestrictionEnzyme[]`。
- 性能：`findCutSites` 对 100 kb 环状序列使用全部 COMMERCIAL_ENZYMES 需 < 400 ms（Node 下测量）。如有必要，可优化扫描算法（例如按识别序列去重后共享扫描结果），但输出语义不得改变。

### A2 Motif 搜索
新增函数：
```ts
export interface MotifHit { start: number; end: number; strand: 1 | -1; mismatches: number; matched: string }
export function searchMotif(doc: PlasmidDocument, pattern: string, opts?: { maxMismatches?: number; bothStrands?: boolean; protein?: boolean; limit?: number }): MotifHit[]
```
- DNA 模式支持 IUPAC 简并码，并支持允许错配（汉明距离）。
- 环状序列支持跨零点命中。
- 两条链都要搜索，负链命中的坐标给出正链区间。
- `protein: true` 时在 6 个阅读框中搜索氨基酸模式（支持 X 通配），返回对应的 DNA 区间。
- 默认上限 1000 条。
- 性能：100 kb、20 bp 模式、2 个错配需 < 200 ms。

### A3 反向翻译与密码子优化
新增函数：
```ts
export type CodonUsageOrganism = 'E. coli' | 'S. cerevisiae' | 'H. sapiens' | 'M. musculus' | 'P. pastoris' | 'D. melanogaster' | 'A. thaliana' | 'CHO';
export const CODON_USAGE: Record<CodonUsageOrganism, Record<string, number>>; // 64 个密码子 -> 每千个密码子的频率（使用 Kazusa/CoCoPUTs 公开数据）
export function backTranslate(protein: string, organism: CodonUsageOrganism, opts?: { strategy?: 'most-frequent' | 'weighted'; avoidSites?: string[]; seed?: number }): string
export function codonAdaptationIndex(dna: string, organism: CodonUsageOrganism): number
```
- `backTranslate` 结果翻译回来必须与原蛋白一致；`avoidSites` 中的识别序列（IUPAC）必须不出现在结果里（用同义密码子替换消除）。
- weighted 策略使用确定性的种子随机数。
