## 任务 E：多序列比对查看器、PDF 导出

### E1 `MultipleAlignmentViewer`
在 index 中导出。组件是纯受控的，数据由 props 传入，组件内不做比对计算：
```ts
export interface MsaViewRow { id: string; name: string; aligned: string }
export interface MultipleAlignmentViewerProps {
  rows: MsaViewRow[];
  consensus: string;
  conservation: number[];        // 0..1
  height?: number;
  theme?: 'light' | 'dark' | 'publication';
  colorScheme?: 'nucleotide' | 'identity' | 'clustal' | 'none';
  referenceRowId?: string;       // 设置后只显示与参考行不同的碱基，相同的显示为 '.'
  onColumnClick?: (column: number) => void;
}
```
- **虚拟滚动**：在 1000 列 × 50 行以内保持流畅；横向、纵向都要虚拟化。左侧固定名称列。
- **顶部**：标尺（每 10 列一个刻度）与保守性条形图。**底部**：共识行。
- **悬停**：显示该行在原序列中的坐标（不计空位）。
- 视觉风格与现有 SangerAlignmentViewer 保持一致，使用 theme.ts 中的 token。

### E2 PDF 导出
