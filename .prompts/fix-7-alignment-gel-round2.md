## 任务 C：多序列比对、双序列全局比对、Ladder 扩充

### C1 多序列比对（纯 TS，可离线运行，不得使用网络或 WASM）
新增以下 API：
```ts
export interface MsaInput { id: string; name: string; sequence: string }
export interface MsaRow { id: string; name: string; aligned: string } // aligned 用 '-' 表示空位；所有行长度相同
export interface MsaResult {
  rows: MsaRow[];               // 与输入顺序一致
  columns: number;
  consensus: string;            // 每列多数碱基；若该列以空位为主则为 '-'
  conservation: number[];       // 每列取值 0..1：与共识一致的非空位行占比
  identityMatrix: number[][];   // 两两百分比同一性（仅计两者均非空位的列）
  guideTree: string;            // Newick 格式
}
export function multipleSequenceAlignment(seqs: MsaInput[], opts?: { match?: number; mismatch?: number; gapOpen?: number; gapExtend?: number; type?: 'dna' | 'protein' }): MsaResult
export interface PairwiseResult { alignedA: string; alignedB: string; score: number; identityPercent: number; startA: number; endA: number; startB: number; endB: number }
export function pairwiseAlign(a: string, b: string, opts?: { mode?: 'global' | 'local' | 'semiglobal'; match?: number; mismatch?: number; gapOpen?: number; gapExtend?: number; type?: 'dna' | 'protein' }): PairwiseResult
```
- **MSA 算法**：k-mer 距离 → UPGMA 或 NJ 引导树 → 按树做 profile-profile 渐进比对（Gotoh 仿射空位），可选一轮迭代精修。
- **蛋白模式**：使用 BLOSUM62。
- **pairwiseAlign**：semiglobal 表示两端空位不罚分。
- **性能**：
  - 8 条约 3 kb 的相关 DNA 序列（测试内用确定性随机突变生成：替换、插入、缺失）MSA < 3000 ms。
  - 两条 10 kb 序列的 pairwiseAlign 全局比对 < 1500 ms。如有需要使用线性空间或 banded 优化，但 global 模式必须正确。
- **正确性测试**：
  - 已知插入/缺失的小例子比对结果正确。
  - 相同序列的同一性为 100。
  - 每一行去掉 '-' 后等于原序列。
  - 共识序列在突变率低时等于原始祖先序列。
