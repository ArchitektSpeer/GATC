## 跨模块约定（模块间不能 import，靠约定对齐）
- **多段特征**（GenBank `join(...)` / SnapGene 多 Segment）：
  - `SequenceFeature.notes.segments = ["s-e", "s-e", ...]`，每段为 0-based 左闭右开的文档坐标字符串（如 `"10-200"`），按生物学顺序排列；负链特征按 5'→3' 顺序。
  - 该特征的 `start`/`end` 为第一段起点到最后一段终点的整体覆盖区间（环状跨零点同样适用）。
  - 没有 `segments` 的特征视为单段。
- **蛋白文档**（schema 中没有，由各模块用相同结构各自声明，不得 import 彼此）：
```ts
export interface ProteinFeature { id: string; name: string; type: string; start: number; end: number; color: string; notes?: Record<string, string[]> } // 氨基酸坐标，0-based 左闭右开
export interface ProteinDocument { id: string; name: string; sequence: string; description?: string; features: ProteinFeature[]; createdAt: string; updatedAt: string }
```
- **FASTQ / 测序读长**：
```ts
export interface SequencingRead { id: string; name: string; sequence: string; qualities: number[] } // Phred
```

### 1. 特征库
`FEATURE_LIBRARY` 扩充到 **≥ 300 个**常用元件，全部使用真实公开序列。可从 NCBI、Addgene 公开序列、iGEM Registry 或 SnapGene 公开的常用特征说明中获取，允许联网查询。覆盖以下类别：
- **启动子**：T7、T3、SP6、lac、lacUV5、tac、trc、araBAD、rhaBAD、tet、CMV、CMV enhancer、EF-1α、PGK、CAG、SV40、RSV、U6、H1、7SK、UbC、CaMV 35S、GAL1、GAL1-10、TEF1、ADH1、TDH3/GPD、AOX1、Polyhedrin、p10、T5 等。
- **终止子 / polyA**：rrnB T1、T2、λ t0、T7 terminator、bGH polyA、SV40 polyA、hGH polyA、CYC1、ADH1 等。
- **抗性基因**：AmpR、KanR、NeoR、CmR、TetR、SmR/SpecR、GentR、ZeoR/Sh ble、HygR、PuroR、BSD、NatR、hph、bar 等。
- **复制起点**：pUC、pMB1、ColE1、p15A、pSC101、R6K、F1 ori、SV40 ori、2μ、CEN/ARS、pBR322、RK2 oriV、pRO1600 等。
- **标签**：His6、FLAG、3xFLAG、HA、Myc、V5、Strep-tag II、GST、MBP、Trx、SUMO、GFP 系列（EGFP、mCherry、mNeonGreen、tdTomato、BFP、mScarlet、YFP、CFP 等）、Luciferase（Fluc、Rluc、Nluc）、TEV/PreScission/Thrombin/Factor Xa/Enterokinase 酶切位点。
- **元件**：IRES、WPRE、cPPT、RRE、LTR、5'/3' ITR (AAV)、attB/attP/attL/attR、loxP 家族、FRT、Kozak、Shine-Dalgarno RBS、MCS、NLS、2A 肽（P2A、T2A、E2A、F2A）、cHS4 绝缘子、gRNA scaffold、Cas9 等。

### 2. 自动注释
`autoAnnotateFeatures` 继续满足以下要求：
- 精确匹配优先。
- 同一区域相似元件只取同一性最高的一个。
- 100 kb 序列 < 50 ms。
- 支持多段蛋白元件：CDS 元件可按蛋白翻译匹配（允许少量氨基酸差异），用于识别经过密码子优化的标签与荧光蛋白。
- pUC19 与 pEGFP-N1 的现有测试仍需通过。

### 3. 双酶切缓冲液推荐
```ts
export interface DoubleDigestRecommendation { buffer: 'r1.1' | 'r2.1' | 'r3.1' | 'rCutSmart' | 'sequential'; activities: Record<string, number>; starActivityWarning: string[]; notes: string[]; temperatureC: number[]; heatInactivation: Record<string, string> }
export function recommendDoubleDigestBuffer(enzymes: RestrictionEnzyme[]): DoubleDigestRecommendation
```
- 为常用酶（至少 120 种）补齐 NEB 四种缓冲液的活性百分比，使用 NEB 公开数据；同时补充孵育温度、热失活条件，以及星号活性风险（如 EcoRI、BamHI、PstI 在高甘油或特定缓冲液中）。
- 推荐规则：选择所有酶活性都 ≥ 75% 的缓冲液；若无，建议分步酶切（sequential），并给出顺序与说明。
- 写测试覆盖 EcoRI+HindIII、BamHI+NotI、需要分步酶切的组合。
