## 跨模块约定（模块间不能 import，靠约定对齐）
- **多段特征**（GenBank `join(...)` / SnapGene 多 Segment）：
  - `SequenceFeature.notes.segments = ["s-e", "s-e", ...]`，每段为 0-based 左闭右开的文档坐标字符串（如 `"10-200"`），按生物学顺序排列；负链特征按 5'→3' 顺序。
  - 该特征的 `start`/`end` 为第一段起点到最后一段终点的整体覆盖区间（环状跨零点同样适用）。
  - 没有 `segments` 的特征视为单段。
- **蛋白文档**（schema 中没有，由各模块用相同结构各自声明，不得 import 彼此）：
```ts
export interface ProteinFeature { id: string; name: string; type: string; start: number; end: number; color: string; notes?: Record<string, string[]> } // 氨基酸坐标，0-based 左闭右开
export interface ProteinDocument { id: string; name: string; sequence: string; description?: string; features: ProteinFeature[]; createdAt: string; updatedAt: string }
```
- **FASTQ / 测序读长**：
```ts
export interface SequencingRead { id: string; name: string; sequence: string; qualities: number[] } // Phred
```

## 任务：MultiSite Gateway、GC 克隆、In-Fusion/NEBuilder、插入片段、引物结合位点搜索

```ts
export function simulateMultiSiteGatewayLR(entryClones: PlasmidDocument[], destination: PlasmidDocument): { expressionClone: PlasmidDocument | null; warnings: string[] }
export function simulateGCCloning(vector: PlasmidDocument, insert: PlasmidDocument, opts?: { orientation?: 'forward' | 'reverse' }): CloningProductResult
export type HomologyAssemblyKit = 'Gibson' | 'NEBuilder HiFi' | 'In-Fusion';
export function designHomologyAssemblyPrimers(fragments: PlasmidDocument[], kit: HomologyAssemblyKit, opts?: { circular?: boolean; overlapLength?: number }): { primers: Array<{ fragmentId: string; forward: Primer; reverse: Primer }>; warnings: string[] }
export function simulateInsertFragment(vector: PlasmidDocument, vectorRange: { start: number; end: number }, insert: PlasmidDocument, insertRange?: { start: number; end: number }, opts?: { reverseInsert?: boolean }): { product: PlasmidDocument; warnings: string[] }
export interface PrimerBindingHit { start: number; end: number; strand: 1 | -1; mismatches: number; mismatchPositions: number[]; threePrimeMatchLength: number; tmAnnealing: number }
export function findPrimerBindingSites(doc: PlasmidDocument, primerSequence: string, opts?: { maxMismatches?: number; minThreePrimeMatch?: number }): PrimerBindingHit[]
```

### MultiSite Gateway
- 处理 2–4 片段 LR：attL1-attR5 / attL5-attL4 / attR4-attR3 / attL3-attL2 等。
- 在 `GATEWAY_ATT_SITES` 中补充 attB/attL/attR 1–5 的公开序列。
- 按 att 位点特异性串接片段，顺序或方向不匹配时给出警告。

### GC 克隆
- 原理与 TA 克隆相同，但突出碱基为 3' G / 3' C（Lucigen GC 克隆）。

### designHomologyAssemblyPrimers 的套件参数
| 套件 | 同源臂 | 重叠区 Tm |
|---|---|---|
| Gibson | 20–40 bp | ≥ 48 °C |
| NEBuilder HiFi | 15–35 bp（默认 20） | ≥ 48 °C |
| In-Fusion | 固定 15 bp 同源臂 | 按 Takara 规则 |

退火区 Tm 都按 SantaLucia 计算，目标 58–62 °C。

### simulateInsertFragment
- 将 insert 的指定区间替换进载体的 vectorRange：start == end 表示纯插入，否则为替换。
- 环状载体允许 vectorRange 跨零点。
- 特征坐标需迁移：被替换区域内的特征删除；与边界相交的特征截断并在 notes 中标注。
- 追加 history。

### findPrimerBindingSites
- 双链搜索，环状序列支持跨零点。
- 允许错配，但 3' 端末尾的 minThreePrimeMatch（默认 10）个碱基必须完全匹配。
- 5' 尾巴不要求匹配。
- 返回结果按 mismatches 升序排列。
