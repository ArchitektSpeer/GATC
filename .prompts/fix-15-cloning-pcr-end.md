## 缺陷修复：线性模板末端的反向引物被误报错配

复现步骤（集成层的演示模式中发现）：
- 模板：`src/app/samples/demo/mCherry.gb`（711 bp，topology 设为 linear）。
- 用 `designPrimerPair(doc, { start: 0, end: 711 }, { enzymeSiteForward: 'BamHI', enzymeSiteReverse: 'NotI', leaderBases: 'GCG' })` 设计引物。
- 得到的反向引物为 `GCGGCGGCCGCTTACTTGTACAGCTCGTCCATGC`，bindingStart 688、bindingEnd 711，与模板完全互补。
- 再调用 `simulatePCR(doc, forward, reverse)`：产物 731 bp 正确，但 warnings 中出现 "Reverse primer annealing region differs from the template at 24 position(s)"，这是误报。

原因推测：引物结合到线性模板最末端（end == length）时，坐标被取模成 0，`sequenceSlice(template, 688, 0)` 在线性模板上返回空串，长度不等，于是按 |差值|+1 计成了错配数。

要求：
- 修复 simulatePCR 以及其他所有可能出现 `end == length` 被取模成 0 的地方（引物结合位点解析、特征切片等），线性与环状模板都要检查。
- 增加回归测试：上面这个 mCherry 用例 warnings 中不得包含 'differs from the template'；正向引物结合在位置 0、反向引物结合在模板末端的线性模板，产物序列与长度正确；环状模板跨零点的情况仍然正确。
- 已有测试全部通过。
