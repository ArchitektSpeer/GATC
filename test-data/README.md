# Test data

Real-world sample files used by integration tests, taken from the MIT-licensed
[TeselaGen tg-oss](https://github.com/TeselaGen/tg-oss) repository
(`packages/bio-parsers/test/testData/`).

| File | Content |
|---|---|
| `example1.ab1` | Sanger chromatogram (1345 bases, uninformative PCON) |
| `addgene-plasmid-50004-sequence-74675.dna` | SnapGene file, pUC18 with primers |
| `addgene-plasmid.dna` | SnapGene file, pAdTrack-CMV with primers |
| `pIB2-SEC13-mEGFP.dna` | SnapGene file with a 9-node cloning history |
| `GFPuv_025_fwdfeature_revfeature_circular.dna` | SnapGene file, forward/reverse features |
